# First Tester Onboarding

1. Clone the repository.
2. Run `npm install`.
3. Run `npm run tester:init -- TESTER-001` using the Tester ID assigned to you.
4. Run `npm run reviewer-kit`.
5. Confirm the final line says `FINAL VERDICT: PASS`.
6. Open `reviewer-kit\artifacts\receipts\allow-receipt.json`.
7. Open `reviewer-kit\artifacts\receipts\refuse-receipt.json`.
8. Run standalone receipt verification on both receipts.
9. Send feedback using `docs/feedback-workflow.md`.

Expected time: 10 minutes.
