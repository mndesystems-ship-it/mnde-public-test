# Feedback Workflow

Send feedback with:

- Tester ID
- Installation ID, if available
- Operating system
- Node.js version
- Command run
- PASS or FAIL result
- Relevant receipt path
- Relevant log path
- Screenshot or copied error text

Recommended format:

```text
Tester ID:
Installation ID:
Command:
Result:
What happened:
Expected:
Attached artifacts:
```

Do not send browser history, credentials, private keys, or unrelated local files.
