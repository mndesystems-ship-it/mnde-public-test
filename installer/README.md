# MNDe Desktop Application

This folder contains the Windows desktop evaluation build:

```text
MNDe-Execution-Control.exe
```

Run it to open the MNDe desktop control surface. The executable is included for external testing only. It does not include private signing keys, local auth sessions, or developer configuration files.

For command-line validation, use the reviewer kit from the repository root:

```powershell
npm run reviewer-kit
```
